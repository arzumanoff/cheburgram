# 🎙 CHEBURGRAM VOICE v3

Программа для голосовых звонков 1-на-1 и текстового чата на базе **Rust**, **Opus** и **egui**.

- **Клиент (`cheburgram-client`):** единый портативный `.exe` для Windows (Linux — тоже собирается). Интерфейс, аудиодвижок, авто-переподключение.
- **Сервер (`cheburgram-server`):** легковесный бинарник / Docker-контейнер для VPS. Сигналинг по TCP, релей аудио по UDP.

## Что нового в v3 (по сравнению с v2)

| Было (v2) | Стало (v3) |
|---|---|
| После первого звонка клиент «глух» до перезапуска | Раздельные stop-флаги сети и аудио; сеть живёт постоянно |
| Нет переподключения при обрыве | Reconnect с backoff (1→30 с) + heartbeat Ping/Pong |
| Захардкожен чужой IP сервера | Адрес только из настроек |
| Звук ломался на USB/Bluetooth гарнитурах (жёсткое mono 48k) | Ресемплинг rubato под любое устройство + fallback |
| «Робоголос» при потерях UDP | Джиттер-буфер + Opus FEC/PLC |
| Кнопки мьюта не работали | Атомики, применяются мгновенно; добавлена громкость собеседника |
| Каждый аудиопакет — JSON (~4× оверхед) | Бинарный заголовок 20 байт |
| Угон чужого ID одной командой | Повторная регистрация под чужим кодом отклоняется (полноценные токены — этап E2) |
| «Призрачные» сессии при повторном входе | Атомарная замена сессии (SessionReplaced) |
| Фиктивный CallAccept создавал звонок | Серверная валидация состояния звонка |
| Статусы онлайн шли всем пользователям | Только друзьям |
| Данные терялись при пересоздании контейнера | Volume `/data` в docker-compose |

## 🚀 Сервер на VPS (Docker)

```bash
git clone <репозиторий>
cd cheburgram
docker compose up -d --build
```

Порты: `7878/tcp` (сигналинг), `7879/udp` (медиа). Реестр пользователей — в volume `cheburgram-data`.

## 🛠 Сборка клиента (Windows .exe)

Требования:
- **Rust** (`rustup.rs`)
- **CMake 3.x** (для статической сборки Opus; ⚠️ CMake 4.x не подходит — несовместим с bundled opus). Проверка: `cmake --version`
- C++ Build Tools (MSVC)

```bash
cargo build --release --bin cheburgram-client
```

Готовый файл: `target/release/cheburgram-client.exe` — переносимый, работает без установки зависимостей (Opus влинкован статически).

## 📱 Использование

1. Запустите клиент, введите имя и адрес сервера (`ip:7878`).
2. Ваш 6-значный ID — на главном экране, передайте его собеседнику.
3. Обменяйтесь заявками в друзья, далее — «📞 Позвонить» или «💬 Чат».

## 🧪 Тесты

```bash
cargo test --workspace
```

34 теста: протокол (round-trip, защита от мусора), джиттер-буфер (потери/переупорядочка/FEC), ресемплер, серверная логика и полноценные E2E (два клиента через живой сервер: звонок, UDP-релей в обе стороны, оффлайн-чат, замена сессии).

## Структура

```
crates/
  protocol/  — бинарный протокол v2 (кадры TCP, заголовок UDP, heartbeat)
  audio/     — аудиодвижок: ресемплинг, jitter buffer, Opus FEC/PLC, мьюты
  server/    — TCP сигналинг + UDP релей (tokio)
  client/    — GUI (egui): app / net / ui / config
```
