# 🎙 CHEBURGRAM VOICE

Программа для прямого защищенного голосового созвона 1-на-1 на базе **Rust**, **Opus** и **egui**.

Проект разработан по схеме:
- **Клиент (`cheburgram-client`):** Единый портативный **`.exe`** файл для Windows/Linux. Содержит интерфейс, аудиодвижок и клиент сигналов/медиа.
- **Сервер (`cheburgram-server`):** Легковесный бинарник и Docker-контейнер для вашего **VPS**. Управляет комнатами по 6-значным кодам и пересылает зашифрованные Opus-пакеты через UDP.

---

## 🚀 Быстрый запуск сервера на VPS (через Docker)

Для разворачивания сервера сигналов и реле на своем VPS достаточно выполнить:

```bash
git clone https://github.com/arzumanoff/cheburgram.git
cd cheburgram

# Запуск в Docker (используйте docker-compose или docker compose):
docker-compose up -d --build
# или
docker compose up -d --build
```

Сервер займет следующие порты:
- `7878/tcp` — Управление комнатами и сигнализация
- `7879/udp` — Передача аудио-пакетов (Opus)

## 🛠 Сборка клиента (Standalone .exe для Windows)

Для сборки одного независимого `.exe` файла клиента:

1. Убедитесь, что установлен **Rust**:
   ```powershell
   rustc --version
   cargo --version
   ```

2. Соберите релизную версию клиента:
   ```powershell
   cargo build --release --bin cheburgram-client
   ```

3. Итоговый файл находится по пути:
   `target/release/cheburgram-client.exe`

Этот `.exe` файл можно скопировать на любой компьютер и запускать без установки дополнительных зависимостей!

## 📱 Как пользоваться приложением

1. Запустите `cheburgram-client.exe`.
2. В поле **VPS Сервер** укажите IP-адрес вашего сервера (например `1.2.3.4:7878`).
3. Выберите микрофон и динамики в блоке "Аудио устройства".
4. Один из участников нажимает **➕ Создать комнату** и получает 6-значный код (например `492-015`).
5. Второй участник вводит полученный код в поле и нажимает **🔗 Войти по коду**.
6. Готово! Созвон начался.

## 🛡 Технические особенности

- **Кодек Opus:** Промышленный стандарт кодирования речи (48 кГц, моно, 20мс фреймы).
- **VU-метр:** Индикатор уровня громкости микрофона в реальном времени.
- **Низкая задержка:** Использование легкого UDP протокола для медиа-потока.
- **Мьюты:** Возможность в один клик отключить микрофон или звук динамиков.
